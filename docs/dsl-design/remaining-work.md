# Следующий этап Astranaut DSL

Русская промежуточная спецификация актуализирована по D377 на 1 ноября 2026 года. Это согласованные требования, не заявление о реализации нового DSL.

В задаче #13 разобраны Q01–Q05: однозначность распределений, вложенные альтернативы, связанные фильтры и уточнение вложенных захватов. Решения D373–D377 включены в §11.9–§11.13 спецификации, ответы сохранены в [журнале задачи](issue-13-matching-decisions.md).

Актуальный список — [§18 спецификации](specification-ru.md#s18): **35 открытых вопросов Q06–Q40** о грамматике, статическом анализе, выполнении, составе первой версии, Unicode, диагностике и последующих этапах. Номера вопросов и групп сохранены для существующих ссылок. Там же остаются проверки преобразователя текста.

[HTML для чтения и печати](specification-ru.html#s18) содержит тот же список. Исторические итоги и аудит A01–A34 в [README.md](README.md) не являются текущим планом; журнал дополнен D373–D377.

Следующую группу выбирает автор. Новые предложения не считаются принятыми без обсуждения; завершение задачи #13 не означает завершения остальных вопросов или реализации.
