# Следующий этап Astranaut DSL

Промежуточная русская спецификация сведена по решениям до D372 на 31 октября 2026 года. Это фиксация согласованной части, не утверждение новых решений и не завершённая реализация.

Актуальные непокрытые вопросы собраны в одном месте — [§18 спецификации](specification-ru.md#s18): 40 отдельных вопросов по сопоставлению, грамматике, статическому анализу, выполнению, составу первой версии, Unicode, диагностике и последующим этапам. Там же сохранён перечень проверок существующего преобразователя текста.

[HTML для чтения и печати](specification-ru.html#s18) содержит те же вопросы. Исторический журнал [README.md](README.md) сохранён без изменений; его аудит A01–A34 отражает прежний срез и не является текущим списком открытых вопросов.

После чтения спецификации автор даст дальнейшие инструкции. Новые предложения не считаются принятыми без обсуждения. Закрытие задачи #10 фиксирует промежуточный этап по поручению автора; реализация и оставшиеся вопросы не объявляются завершёнными.
