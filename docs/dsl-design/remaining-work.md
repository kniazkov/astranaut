## Что не обсуждать заново

- D317–D340: Character, кодовые точки, диапазоны, экранирование, CodePoint и накопление символов уже определены.
- D341–D349: один результирующий узел, строки и chars при построении детей определены.
- D350–D357, D361–D362: действия исполняются отдельным проходом; явный none удаляет узел или совпавшую цепочку атомарно, сохраняя корректность; можно удалить корень.
- D358–D360 отменены. Необязательный самостоятельный результат запрещён; обязательное место нельзя заполнить необязательным захватом или несовместимым статическим типом.
- D357 уже различает доказанную невозможность правила вообще и неприменимость в отдельном контексте. Этот общий вопрос A23 закрыт; анализ перекрытия с учётом отказов результата ещё требует проверки.
- D363: текстовый вход и вход готового дерева подтверждены; существующий текстовый преобразователь нужно проверить.

## Критические блоки до завершения спецификации

Это шесть групп работ, не обещание обойтись шестью вопросами.

1. **Единый смысл неоднозначности и логики (A01–A05, A07).** Разграничить статически запрещённые разбиения и допустимые шаблоны с отказом на конкретном входе. A03 закрыт D364: неоднозначность внутри отрицания отвергает весь кандидат, в том числе при двойном отрицании. Уточнить общий выбор вложенных альтернатив/аккумуляторов и совместную проверку ссылок на данные. Решённый контрольный пример: !(Box[Statement*, Return, Statement*]) на двух Return отвергает кандидат. Сохранить принятый допустимый шаблон D179.
2. **Однозначная грамматика (A08–A11).** Область действия as относительно |, запятой и & определена D365: ближайший шаблон, расширение через скобки. Остались вложенные захваты, прочие сочетания синтаксиса, сокращённые строковые условия, лексические формы и сигнатуры вызовов. Составить EBNF и таблицы приоритетов. Разбор A | B as x решён: A | (B as x). Уже определённые приоритеты не пересматривать.
3. **Статическая совместимость и построение (A06, A13–A19).** Уточнение внутреннего захвата пересечением; категория и кратность объединений в детях; корреляции веток; непорождаемые рекурсивные схемы; неверный default; граница анализа пользовательского Java. Запреты D361 сохраняются. A17 касается прежде всего выражений детей: запрет цепочки как самостоятельного результата уже принят.
4. **Полный контракт выполнения (A20–A24).** Допустимые шаблоны в одноузловом контексте; единый порядок обработки смешанных дочерних мест и реконструкции родителя; проверка симметрии поиска <-; результат запуска при ошибке после успешных замен. Общий порядок снизу вверх, конкуренция в группах и отсутствие спуска в новые поддеревья уже приняты. Не проектировать Java API Node.
5. **Граница первой версии (A31 и оставшаяся часть A32).** Явно включить либо отложить наборы правил, именованные проходы, языковые секции и пространства имён. Для режима разбора текста определить, как отличить готовый результат от остановки с необработанными символами. Символьный конвертер уже существует по сообщению пользователя; его проверка — задача реализации.
6. **Согласованный документ и проверяемые примеры (A29–A30).** Удалить устаревшие открытые вопросы из действующей спецификации, сохранить историю отмен, собрать EBNF и положительные/отрицательные примеры. Это работа по сведению документов; задавать пользователю только реально обнаруженные семантические развилки.
